# Inline

## Qué es

Un caso específico del método en línea se presenta cuando tenemos uno o más métodos cuyo código es
lo suficientemente autoexplicativo como para poder prescindir de ellos: basta con sustituir las
llamadas al método por el cuerpo de dicho método.

Esto también ocurre con las variables: en ocasiones se tiene una variable que solo se usa para
almacenar un valor y posteriormente retornarlo.

## Ejercicio

Toma la clase `Termometro` y trata de dejar en una sola línea lo que sea necesario para hacer el
código más limpio.
