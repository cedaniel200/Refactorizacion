# Rename

## Qué es

Se cambia el nombre de variables, métodos o clases según sea el caso, con el fin de tener un código
limpio; de esta forma el código es más legible y mantenible, entre otras características.

## Ejercicio

Toma la clase `Termometro` y cambia los nombres que sean necesarios para que sea más legible y
mantenible, es decir, para que sea un código más limpio.

## Pistas

- Si renombras los métodos con las herramientas del IDE no deberías tener ningún problema.
- Si los renombras a mano, cambia también el test: es muy probable que el método al que hace
  referencia ya no se llame igual.
